# Visual 3D Ruang Server Kayreach — 12 Oktober 2026

Model web diekspor langsung dari file `Ruang Server Kayreach - Visual 3D.blend` yang diunggah pengguna pada 12 Oktober 2026. Sumber asli tidak diubah. File Blender yang dapat diunduh identik dengan unggahan. Browser menampilkan ekspor GLB; Three.js dan pustaka tersedia lokal.

Model dapat diputar, diperbesar, dilihat dari atas, serta menampilkan garis ukuran. Klik sensor, server/rak dan Mini PC membuka detail. Klik pintu atau tombol pintu untuk membuka/menutup.

Geometri mengikuti file unggahan, termasuk meja dan Mini PC yang dipindahkan. Garis sensor–Mini PC dalam file bernama 3,468 m, dan meja–ruang server 2,0 m. Angka ini merupakan ukuran model, belum dikonfirmasi sebagai pengukuran lapangan di vault. Jarak lapangan sensor–Mini PC tetap 1,5 m; tinggi sensor 1,798 m dan jarak sensor–server 0,636 m. Geometri tidak dipakai untuk simulasi aliran udara atau jangkauan radio.

Spesifikasi panel perangkat mengikuti vault. Status lima layanan Mini PC berasal dari pemeriksaan 4 Oktober 2026 pukul 17:22:09 WIB, bukan status langsung. Metadata lama dalam Blender tetap dipertahankan apa adanya; lihat `model_source.json` untuk asal file, hash sumber, dan catatan perbedaan ukuran.

Render perspektif dibuat ulang dari file unggahan. Naskah skripsi, gambar Bab 3, HTML mandiri dan ZIP arsip 5 Oktober belum disinkronkan dengan geometri unggahan ini.
